# Centralized Procurement Vendor Management Simulation

This Python example simulates a centralized procurement system with a global vendor address book. It demonstrates how different departments submit purchase requests to a central authority, which then validates and processes these requests against a unified, centrally managed list of approved vendors. This approach highlights the benefits of consistent vendor data and streamlined purchasing processes, reducing inefficiencies and ensuring compliance.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Open a terminal or command prompt.
3. Run the script using: `python main.py`
